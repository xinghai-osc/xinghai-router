# Xinghai UI 设计语言

## 布局

公共站点使用 80rem 最大宽度的 `shell` 容器，移动端左右留白 20px，桌面端 32px。首页通过双栏首屏、分组能力卡片和独立行动区组织内容。

控制台采用 16rem 侧栏与内嵌工作区；折叠侧栏为 4.5rem，1024px 以下改为抽屉导航。内容最大宽度为 96rem，移动端留白 16px，桌面端逐级提升至 40px。操作栏在窄屏纵向排列，表格仅在自己的容器内横向滚动。

## 视觉层级

默认采用无衬线标题，字重 650、紧凑字距，正文保持宽松行高。标题、说明、操作按钮构成页面头部；数值使用 `numeric`，金额与统计沿用统一格式化函数。主题预设可以保留各自字体和圆角覆写。

页面底色、卡片表面、内嵌区域分别使用 `paper`、`surface`、`sunken`。`line` 用于结构边界，`line-strong` 用于较强分隔；`clay` 为唯一主要强调色，成功、警告、危险状态保留语义色。所有配色通过现有主题变量提供。

默认卡片圆角为 20px，输入框与按钮为 10px。以细边框、留白和背景层次区分内容；阴影保留给弹层。非交互卡片的反馈只强化视觉，不暗示可点击。

## 动效

参考 Prompt Motion 的产品界面展示方向，将动效用于信息出现顺序与操作反馈。

- 导航、按钮、图标和边界反馈：150ms ease-out。
- 控制台分区入场：420ms，分区延迟 60ms；统计卡片以 40ms 递进。
- 首页首屏：640ms 分层入场；装饰背景仅淡入一次。
- 悬停位移仅用于支持悬停的设备，幅度保持 2–3px。
- 所有新入场动画尊重 `prefers-reduced-motion`，关闭位移和动画后内容仍立即可见。

避免持续自动运动、数字滚动和布局尺寸动画，确保阅读与高频操作稳定。

## 组件和可访问性

共享卡片、表格、标签页、输入框和选择器承载一致的间距、边框和聚焦状态。所有业务页面继续组合现有 Ui 组件，不引入第二套组件体系。

导航当前项同时具有颜色和边缘标记。公共站点与控制台均提供跳至正文链接；移动端保留导航抽屉或菜单，表单和按钮保持原有键盘交互与可访问名称。所有可见文案继续走现有 i18n。
