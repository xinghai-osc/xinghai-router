# Xinghai UI 设计语言

## 设计参考

参考 [映间 MARGIN](https://github.com/jiuyang5354/bilibili-margin) 的编辑式排版、宽幅搜索、玻璃控件与内容分区。以星海的模型发现、网关接入和账户运营为核心，保留现有接口、权限及业务流程。

## 布局

公共站点使用 80rem 最大宽度的 shell 容器，移动端留白 20px，桌面端 32px。首页依次展示首屏搜索与交互接入预览、模型目录、可选视频、能力介绍、订阅定价和注册入口。模型搜索直接进入模型广场并保留查询条件。

控制台使用悬浮侧栏，展开时网格轨道宽 18rem，折叠时为 6.5rem；侧栏外边距 16px，1024px 以下使用抽屉。工作区最大宽度 96rem，左右留白从手机端 16px 增至桌面端 48px。统计区按账户资金、本月用量分组，调用热力图独占一行。表格在自身容器内横向滚动。

## 视觉层级

默认主题为映间 Margin：暖纸底色、青绿强调、衬线展示标题、半透明玻璃面板和细边框。已有用户的主题选择继续保留；所有原有主题仍可切换，每个预设保持浅色与深色模式。

Margin 展示标题使用系统衬线字体，正文与控件使用系统无衬线字体。金额和统计使用 numeric 及统一格式化函数，手机端数字字号减小以容纳单位。

页面底色、面板和内嵌区域分别使用 paper、surface、sunken；line 与 line-strong 区分边界强度；clay 为主要强调色。成功、警告、危险状态使用独立语义 token。组件中不写入固定颜色。

Margin 卡片圆角 24px、表单控件圆角 14px、按钮为胶囊形。侧栏圆角 28px。用留白和细分隔线组织内容；高光用于玻璃表面，弹层保留阴影。

## 动效与可访问性

操作反馈以 150ms 的颜色、透明度和小幅位移为主。液态玻璃主题采用缓慢背景渐变，减少动态效果时停止；减少透明效果时恢复实色面板。数据和正文保持稳定，不做数字滚动或布局尺寸动画。

公共站点与控制台均提供跳至正文链接。手机菜单支持关闭和 Escape；控制台抽屉使用现有 Reka Dialog。快捷导航复用侧栏的权限定义，支持 Ctrl/⌘ K、斜线、方向键和 Enter，并提供无结果状态。

## 实现约定

继续使用现有 Ui 组件和语义 token，不引入新依赖。新增文案同步简体中文、繁体中文和英文。保留模型与定价加载/空/错误状态、权限控制、账户与工作空间切换和已有 API 行为。
