# 订阅等级、价格与额度

按套餐售价 ÷ 0.08 推导周期总额度，取整时优先尾数 6 或 8；偏差超过 5% 时取最近整数。额度是平台计费额，不是固定 token 数。额度用尽后所有等级均停止订阅覆盖，不自动扣钱包。年付额度是完整年周期总额，不按月重置。

- 原 L1 → Core，原 L2 → Pro；Aria 原单等级 → Core。Max 是新增档。

- 当前总计仍为 170 个订阅、32 个 active、32 条模型用量记录；迁移事务对实例状态、周期、原价、剩余额度及模型用量做前后校验，未重置计数。
- 现有订阅本周期的已购价格和额度继续保留；下一次续费使用映射后新等级的价格与额度（已获用户确认）。新等级无单模型额度，因此现存模型专属额度会在该实例首次按新等级续期时不再重新生成。
- 待支付旧订单数为 0；历史订单名称快照保留，订单 tier 引用映射到新等级。
